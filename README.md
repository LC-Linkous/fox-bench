# fox-bench

A browser workbench for small amateur-radio fox transmitters (CircuitPython
board + NiceRF SA868): configure, deploy, preview what it will transmit,
test it, and keep a log of the fleet. Chrome or Edge; nothing to install.

Status: design phase. Start with `DESIGN.md` (architecture) and
`CONFIG.md` (the `fox.json` contract).
